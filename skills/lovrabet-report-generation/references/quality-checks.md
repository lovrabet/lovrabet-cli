# 报告质量检查

原子执行及完整指标契约规则使用 `lovrabet` 的 `guides/metric-consumption.md`。此表用于报告计算和解释，按任务涉及项检查，不强求所有接口具有同一结果字段。

| 项目 | 要确认什么 |
| --- | --- |
| 对象、范围、单位 | 实际执行与用户确认一致；总量与子集、笔数与人数不互换，币种/单位转换须有可信依据 |
| 时间 | 统计事件、期间/快照、时区、区间边界可比；生成时间不是数据完整截止时间 |
| 空与失败 | 零、空集合、缺失、未知、权限拒绝、执行失败分别表达；结构校验通过不代表口径正确 |
| 总量、分母与重聚合 | 优先使用服务端区间结果；重聚合须核对可加性、完整互斥、同口径与数据状态；当前页/TopN不充当总体，期间去重人数不逐日相加，快照不跨日求和，比例/均值用汇总分子分母重算 |
| 覆盖与归因 | 全量取数不等于关联归因完整；未归因保留，不分摊到已知对象；未知水位不宣称完整 |
| 精度与对账 | BFF/底层服务负责精确计算与返回表示，CLI 校验并原样透传；精确字符串不转普通 Number，展示舍入值不作聚合输入；保持既有业务舍入时点（含逐行结算），有可信来源时对账，不猜测差异原因 |
| 变化与解释 | 比较双方范围、口径和覆盖一致；无可信阈值不定义异常，无证据不把相关性写成原因 |
| 追溯 | 留最小来源、参数/期间、取数时点和产物引用；观察到的定义不等于执行锁版，多次查询不自动构成同一快照 |

缺少证据时缩小结论到可确认范围。不存在适用分母时不生成百分比；数据不支持因果时说明观察及可验证的下一步，不为丰富报告添加判断。
