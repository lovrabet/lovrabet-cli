# 企业业务流程复用

按任务、可信企业/应用上下文、已发现 Skill 的适用范围和实际能力选择，不用特定企业或 Skill 名称白名单。专用流程能完成任务就直接用；综合任务才由通用报告组织。没有企业 Skill 不影响使用其他可信能力。

取数、生成产物、投递各自选择一条适用且获授权的执行路径。复用是读取指引及已有执行能力，不要求串行运行全部 Skill。

| 情况 | 执行方式 |
| --- | --- |
| 用户范围与业务默认值不同 | 传递已确认对象、期间、时区、口径和受众；默认只补未指定项。不支持则说明限制，不能静默覆盖 |
| 资料与当前契约冲突 | 核对可信业务依据及云端契约，影响结论时交相应负责人；不能绕过指标失败或扩大权限 |
| 已有数据 | 当前权限、身份/企业/应用、对象、参数、期间、口径、单位、数据时点和覆盖适用时复用；有变化只重取受影响部分并说明原因 |
| 专用脚本自己查询 | 先决定由它取数，不预先再查一次。只有接口真实支持传入事实时才能传入结果，不编造参数、不跳过校验 |
| 已有报告或不可变快照 | 已满足目标则返回引用；综合报告只补需要的新内容并保留来源。用户明确改范围/内容时依原修订机制生成，不覆盖不可变快照 |
| 投递已执行或未知 | 一次投递意图仅走一个授权路径；专用流程承担后仅读其记录。已送达不重发，未知先核查原记录，无依据则保持未知；生成成功不等于送达 |
| 专用流程缺口 | 返回已完成项、证据/产物引用和未完成项，说明受影响范围 |

必要的权限/契约复验不属于无意义重复。沿用既有报告标识、修订及收件人状态；没有可靠回执或幂等保证时，不自动重发，也不承诺严格一次投递。

企业的指标、固定日历、阈值、栏目、受众策略和建议仅在其适用场景生效。客户建议策略不能改变统计、权限、口径、产品机制问题的责任归属。稳定业务规则继续由企业 Skill 维护，重复统计由其已有共享能力承担；普通报告不强制新建业务 Skill 或迁移全部旧入口。
