# 业务报告与分析

指标体系是应用级的可选复用能力，不是生成报告的前置条件。从用户的业务目标完成可核验的报告。先保留已确认的范围和已有结果，只补充影响结论的信息。用户无需提供指标名、SQL 或技术 Prompt。

使用已安装的 `lovrabet` Skill 核对认证、应用及原子能力；按其实际资源位置读取 `guides/metric-consumption.md`。通过宿主 Skill 发现能力按名称加载，不假定安装目录相邻。缺少主 Skill 时说明相关能力不可用，交管理员修复；已有可独立完成任务的企业 Skill 可继续在其授权内执行。

| 当前任务 | 阅读并执行 |
| --- | --- |
| 新报告、统计比较或修改表达 | [报告流程](references/report-workflow.md)；涉及计算时读[质量检查](references/quality-checks.md) |
| 已有企业业务 Skill 或已有产物 | [业务流程复用](references/business-skill-reuse.md) |

本 Skill 负责报告取数、核验与表达；任务管理、协作和会话上下文获取由 Agent 与宿主负责。

默认在会话内交付；格式按用户需要选择，结构可参考[报告提纲](templates/report-outline.md)。按需加载指引，复用适用结果与产物，不重复取数、生成或投递。

提问用于澄清业务目标、范围、完成标准和未知口径，技术实现路径由 Agent 自主判断。确需开发能力时转入主 `lovrabet` 的开发能力交接，不默认让用户选择建设路径，也不在报告流程内另建研发流程。权限问题交管理员，口径争议请业务负责人确认；路径判断不扩大操作授权。独立可完成部分继续，缺项明确说明。保存业务 Skill、建订阅、对外投递须有对应授权，生成报告本身不授权这些动作。
